# BRADO — Boutique de Carnes de Origem

Site de lançamento da BRADO em Marabá, Pará.

Endereço: https://bradocarnes.com.br/

## Estrutura

- `index.html`: apresentação, seleção de cortes, origens, boutique e lançamento.
- `styles.css`: identidade bordô e marfim, layouts responsivos e redução de movimento.
- `app.js`: menu, abas acessíveis por teclado, detalhes dos cortes, privacidade e compartilhamento.
- `brado-logo-oficial.jpg`: arquivo oficial fornecido pelo proprietário, preservado sem alteração.
- `*.webp`: imagens ilustrativas geradas para o lançamento, comprimidas sem mudança da composição.
- `favicon.svg`: enquadramento do monograma oficial, sem redesenho.
- `CNAME`: domínio oficial `bradocarnes.com.br`.
- `.nojekyll`: publicação estática direta, sem compilação.

## Publicação

GitHub Pages publica a branch `main`, pasta `/ (root)`. Não há dependências de produção, compilação, segredos ou servidor. Alterações publicadas na branch são disponibilizadas pelo fluxo automático do GitHub Pages.

## Conteúdo de lançamento

O site comunica **em breve**. Não anuncia data, endereço de rua, canais de pedidos, preços ou estoque antes de confirmação. Brasil, Uruguai, Argentina e Japão são apresentados como origens que inspiram a seleção em preparação, sem atribuir fornecedores, certificações, grau A5, importação direta ou disponibilidade a produtos ainda não contratados.

O site apresenta a boutique; não oferece consumo de carnes preparadas no local. Delivery e atendimento reservado fazem parte do conceito anunciado.

Não há formulário, armazenamento de dados de visitantes ou simulação de cadastro. O compartilhamento utiliza a função nativa do dispositivo ou copia o endereço público. A política de privacidade informa o papel do provedor de hospedagem.
